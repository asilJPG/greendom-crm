# Облачная копия склада (Vercel)

Приёмник данных от моноблока и сайт для просмотра: остатки, отчёт, история. Только чтение, менять данные с сайта нельзя.

```
Моноблок ──(новые операции, по ключу)──▶ /api/ingest ──▶ Postgres (Neon)
                                                              ▲
Телефон / компьютер ──(пароль)──▶ сайт ──▶ /api/stock, /report, /movements
```

## Что внутри
| Файл | Назначение |
|---|---|
| `api/ingest.js` | приём операций от моноблока (только с секретным ключом, повторы безопасны) |
| `api/login.js`, `logout.js` | вход на сайт по паролю, блокировка после 5 неверных попыток на 15 минут |
| `api/stock.js`, `report.js`, `movements.js`, `status.js` | данные для сайта (только после входа) |
| `public/index.html` | сайт: остатки, отчёт за период, история; работает на телефоне |
| `lib/` | база, вход, общие функции |
| `test/` | проверки на локальном Postgres (`npm test`), локальный стенд (`node test/devserver.js`) |

## Переменные окружения (Vercel → Settings → Environment Variables)
См. `.env.example`. Всего четыре: `DATABASE_URL` (подставится сама при подключении Neon), `INGEST_TOKEN` (ключ для моноблока), `DASHBOARD_PASSWORDS` (пароли для входа на сайт, через запятую), `SESSION_SECRET` (подпись входа). Настоящие значения никуда в файлы не записываются.

## Развёртывание (когда будет ваше «да»)
1. Проект в Vercel и база Postgres (Neon через Vercel Marketplace).
2. Четыре переменные окружения: ключи генерируются случайно, пароль для сайта задаёте вы.
3. Публикация проекта, адрес вида `https://имя.vercel.app`.
4. В `config.json` моноблока: `sync.url` = `https://имя.vercel.app/api/ingest`, `sync.token` = `INGEST_TOKEN`.
5. Проверка: запись на моноблоке появляется на сайте.

## Безопасность
- Данные приходят только с секретным ключом. Сайт закрыт паролем (не PIN из 4 цифр), сессия 12 часов.
- Пароль на сайт проверяется на сервере, подбор ограничен (5 попыток, потом 15 минут блокировки с одного адреса).
- Сайт не индексируется поисковиками (`noindex`).
- Таблицы в облаке содержат продажи и суммы: пароль для сайта давайте только тем, кому эти цифры можно видеть.
